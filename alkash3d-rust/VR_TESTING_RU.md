# Проверка VR

1. Подключите шлем к ПК и запустите SteamVR либо приложение производителя шлема.
2. В SteamVR: `Settings -> OpenXR -> Set SteamVR as OpenXR Runtime`.
3. Дважды нажмите `run_xr_probe.bat`. Успех: выводит имя runtime, имя шлема и рекомендуемое разрешение каждого глаза.
4. Дважды нажмите `run_xr_demo.bat`. В шлеме появятся тёмный пол, голубой центральный куб, красный и зелёный ориентиры по сторонам. Движение головы должно менять перспективу.

Скрипты сами находят `openxr_loader.dll` из стандартной установки SteamVR — вручную менять `PATH` не надо.

Если probe сообщает `No VR headset is available`, это не сбой сборки: проверьте кабель/Link, питание шлема и что SteamVR показывает шлем зелёным. Если runtime не SteamVR (например, Meta Quest Link), выберите его активным OpenXR runtime в приложении производителя и запускайте те же скрипты.

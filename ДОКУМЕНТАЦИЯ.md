> Полное руководство для новичка, который только начал писать на **Rust**.

**AlKAsH3D** — собственный игровой движок, написанный на Rust поверх «сырого»
DirectX 12. Он заточен под симуляции открытого мира (флагманское демо — игра в

движок для любого жанра».

## 1. Введение: что такое AlKAsH3D

AlKAsH3D — это **собственный игровой движок**, написанный с нуля на **Rust**
поверх **DirectX 12** (без готового рендер-фреймворка поверх API). Работает
только на **Windows 10/11** с GPU, поддерживающим DirectX 12.

### Что умеет движок (по подсистемам)

| Подсистема | Что даёт |
|------------|----------|
| **Рендеринг** | DirectX 12 «вручную»: HDR, каскадные тени (CSM), volumetric (god rays), bloom + tonemapping, SSAO, GI (DDGI), TAA, отражения лучами, фрустум- и окклюжен-каллинг |
| **Физика** | Плагин `inertial.dll` (солвер на **Fortran** за Rust FFI): broad/narrow phase, контакты, шарниры (шар/петля/сварка/ползун), raycast, отдельная физика машины |
| **Звук** | XAudio2 (встроен в Windows 8+, ничего ставить не надо), 2D/3D звук, банки `.alsnd` |
| **Скриптинг** | Один C-ABI для трёх языков: **Native** (Rust/C++ DLL), **Lua** (DLL-рантайм), **Python** (RustPython, hot-reload) |
| **Сцена/ECS** | Генерационные индексы (стабильные `EntityId`), иерархия parent/child, компоненты |
| **Файлы** | Свои бинарные форматы: `.altex`, `.alworld`, `.alfar`, `.alcar`, `.alasm`, `.alroute`, `.almat`, `.alps`, `.alsnd`, `.alscript`, `.aluv` |
| **Планировщик** | Многопоточный планировщик задач (4–8 ядер) |
| **Редактор** | `alkash3d-editor` на egui/wgpu — сцена, гизмо, undo/redo, импорт `.obj`/`.gltf`/`.fbx`/`.blend` |

### Структура репозитория

| Папка | Что это |
|-------|---------|
| `alkash3d-rust/` | **Ядро движка**: рендерер, ECS, физика, звук, скриптинг, форматы, демо-бинарики |
| `alkash3d-inertial/` | Физический плагин `inertial.dll` (Fortran-солвер за Rust FFI) |
| `alkash3d-FirstFires/` | Плагин отсечения света `alkash3d_firstfires.dll` (culling по сетке) |
| `alkash3d-luascript/` | Универсальный Lua-плагин `alkash3d_luascript.dll` |
| `alkash3d-examplescript/` | Референсный нативный Rust-плагин скриптинга (шаблон) |
| `alkash3d-editorapp/` | Редактор на egui/wgpu, линкуется с `alkash3d_rs` как библиотекой |
| `alkash3d-execfile/` | Минимальный `.obj`-вьювер, проверяющий C-ABI движка |
| `alkash3d-msts/` | Загрузчик маршрутов/подвижного состава MSTS |
| `tools/`, `data/` | Вспомогательные инструменты и данные (карты, профили камер) |

### Как организован код ядра (`alkash3d-rust/src/`)

- `lib.rs` — корень библиотеки, все `pub use` (публичный API = `alkash3d_rs::*`).
- `engine/mod.rs` — главный тип **`AlkashEngine`** (все поля) и мелкие методы.
- `engine/lifecycle.rs` — жизненный цикл: `new`, `init`, `update`, `shutdown`, `Drop`.
- `engine/mesh.rs`, `engine/mesh_api.rs` — геометрия (`Vertex`, `Mesh`, `MeshInstance`) и API добавления мешей/сущностей.
- `engine/physics_bridge.rs` — мост к плагинам физики/света + звуку.
- `engine/scripting.rs`, `engine/scripting_python.rs` — скриптинг (Native/Lua/Python).
- `engine/world_streaming.rs` — стриминг открытого мира.
- `engine/assembly.rs` — спавн `.alasm`-сборок.
- `engine/asset_loading.rs`, `engine/gltf_load.rs` — загрузка `.altex` и glTF.
- `engine/render_frame.rs` — главный проход рендера кадра.
- `engine/pipeline_*.rs` — отдельные проходы рендера (shadow/post/ssao/volumetric/occluder/main).
- `scene.rs` — ECS-сцена (`Scene`, `EntityId`, `Transform`).
- `camera.rs`, `math.rs`, `input.rs` — камера, математика (glam), ввод.
- `audio.rs` — XAudio2.
- `plugin/` — система плагинов (ABI + безопасные обёртки).
- `scheduler/` — планировщик задач.
- `*_format.rs` — по одному модулю на каждый файловый формат.

### Главные понятия для начала

1. **`AlkashEngine`** — один экземпляр на всю игру. Всё держится в нём: сцена,
   физика, звук, рендерер, ввод.
2. **Меш (`Mesh`)** — геометрия (куб, плоскость, модель). Создаётся через
   `engine.add_cube(...)` и т.п., возвращает **индекс** (`usize`).
3. **Инстанс (`MeshInstance`)** — «экземпляр» меша в мире: позиция + поворот +
   масштаб. Один и тот же меш можно нарисовать много раз.
4. **ECS-сцена (`Scene`)** — более современная альтернатива `mesh_instances`:
   сущности (`EntityId`) с компонентами (`Transform`, `MeshRenderer`, …).
5. **Игровой цикл** — `process_messages()` → `update(...)` → `render_frame()`,
   повторяется пока `is_running()`.

## 2. Установка и сборка

### Что нужно

**Для разработки:**
- **Windows 10/11** и видеокарта с поддержкой **DirectX 12**.
- **Rust** (стабильный канал). Ядро `alkash3d-rust` использует **edition 2024**,
  остальные крейты — 2021. Установить: https://rustup.rs
- **gfortran** — нужен только для физического плагина `alkash3d-inertial`.
  На Windows — через **MSYS2** (пакет `mingw-w64-x86_64-gcc-fortran`) **и**
  Rust-цель `x86_64-pc-windows-gnu`.
- **Visual Studio 2022** (компоненты C++) — для остальных нативных плагинов.

**Для запуска:**
- **Windows 10/11**, GPU с DirectX 12.
- Плагины (опционально, грузятся в рантайме): `inertial.dll`, `alkash3d_firstfires.dll`,
  `alkash3d_luascript.dll`.

### Установка Rust

```bash
# https://rustup.rs  →  установить "MSVC" toolchain (default)
rustc --version
cargo --version
```

### Установка gfortran (только если нужна физика)

1. Поставить **MSYS2**: https://www.msys2.org
2. В терминале MSYS2 (MINGW64):
   ```bash
   pacman -S mingw-w64-x86_64-gcc-fortran
   ```
3. Добавить цель GNU в Rust:
   ```bash
   rustup target add x86_64-pc-windows-gnu
   ```

### Сборка

```bash
git clone <URL репозитория>
cd AlKAsH3D-Engine

# 1) Физический плагин (нужен gfortran + x86_64-pc-windows-gnu)
cd alkash3d-inertial
cargo build --release
cd ..

# 2) Плагин отсечения света (нужен MSVC/C++)
cd alkash3d-FirstFires
cargo build --release
cd ..

# 3) Lua-плагин (нужен MSVC/C++)
cd alkash3d-luascript
cargo build --release
cd ..

# 4) Сам движок
cd alkash3d-rust
cargo build --release

# 5) Запустить демо машины
cargo run --bin main_car
```

Другие части:

```bash
cd alkash3d-editorapp && cargo run --release   # редактор
cd alkash3d-execfile && cargo run --release    # C-ABI вьювер
```

### Профиль release

```toml
[profile.release]
opt-level = 3
lto = true
```

Для реальной производительности демо запускай через `cargo run --release`.

### Возможные проблемы при сборке

- **«LoadLibraryExW failed» / `ERROR_MOD_NOT_FOUND`** — плагин не найден; убедись,
  что DLL собраны (движок сам пробует запасной путь `.../target/<профиль>/deps/`).
- **gfortran не найден** — установи MSYS2 + `x86_64-pc-windows-gnu`.
- **Ошибки MSVC/C++** — нужны компоненты C++ Visual Studio 2022.

## 3. Твоя первая программа

### Где писать код

1. **Внутри `alkash3d-rust`** — добавить файл `src/bin/my_game.rs` и запускать
   `cargo run --bin my_game`. (Так сделаны все демо.)
2. **Отдельным крейтом** — добавить зависимость `alkash3d_rs = { path = "../alkash3d-rust" }`.

### Минимальная программа (куб в окне)

```rust
// src/bin/hello.rs
use alkash3d_rs::engine::{AlkashEngine, MeshInstance};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 1) Создаём движок с окном 1280×720
    let mut engine = AlkashEngine::new(1280, 720);

    // 2) Инициализируем: создаётся окно Win32, D3D12-устройство, все пайплайны
    engine.init()?;

    // 3) Строим сцену: куб размером 1.0 и пол
    let cube = engine.add_cube(1.0);
    engine.mesh_instances.push(MeshInstance::new(cube).at(0.0, 1.0, 0.0));

    let floor = engine.add_quad(0.0, 0.0, 10.0, 10.0, [0.3, 0.3, 0.4, 1.0]);
    engine.mesh_instances.push(
        MeshInstance::new(floor)
            .at(0.0, 0.0, 0.0)
            .rotated(-1.5708, 0.0, 0.0),   // -π/2 по X — положить плоскость на пол
    );

    // 4) Игровой цикл
    let start = std::time::Instant::now();
    let mut last = 0.0f32;
    while engine.is_running() {
        engine.process_messages();          // события окна и клавиатуры

        let now = start.elapsed().as_secs_f32();
        let dt = now - last;                // время кадра
        last = now;

        let view_proj = engine.camera.projection_matrix() * engine.camera.view_matrix();
        let cam_pos = [engine.camera.position.x, engine.camera.position.y, engine.camera.position.z];

        engine.update(dt, -9.8, cam_pos, view_proj.to_cols_array());
        engine.render_frame()?;
    }

    // 5) Чистое завершение
    engine.shutdown();
    println!("Goodbye!");
    Ok(())
}
```

Запуск: `cargo run --bin hello`.

### Разбор по строкам

- `use alkash3d_rs::engine::{AlkashEngine, MeshInstance};` — `alkash3d_rs` это имя
  библиотеки (пакет `alkash3d_rs`), `AlkashEngine` — главный тип, `MeshInstance` —
  «экземпляр меша» в мире.
- `AlkashEngine::new(1280, 720)` — ширина/высота окна. **Окно ещё не создано**.
- `engine.init()?` — создаёт окно Win32, D3D12-устройство, swap chain, компилирует
  шейдеры, создаёт все пайплайны. Возвращает `Result` (поэтому `main` возвращает `Result`).
- `engine.add_cube(1.0)` — создаёт меш-куб и возвращает его индекс (`usize`).
- `MeshInstance::new(cube).at(0.0, 1.0, 0.0)` — builder-паттерн: `.at()/.rotated()/.scaled()`
  возвращают `Self`, можно писать цепочкой.
- `engine.add_quad(...)` — плоскость `10×10` с цветом RGBA; повёрнута на −π/2 по X, чтобы стать полом.
- `engine.is_running()` — `true`, пока окно не закрыли и не вызвали `request_exit()`.
- `engine.process_messages()` — **обязательно каждый кадр**: разбирает сообщения
  Windows и обновляет `engine.input`.
- `engine.update(dt, gravity, cam_pos, view_proj)` — тикает физику, скрипты,
  день/ночь, стриминг, каллинг света, звук.
- `engine.render_frame()?` — рисует кадр и выводит на экран.
- `engine.shutdown()` — освобождает GPU-ресурсы. `AlkashEngine` реализует `Drop`,
  так что shutdown вызовется автоматически, даже при панике.

### Добавляем движение (вращение куба)

```rust
// внутри цикла, перед render_frame():
if let Some(instance) = engine.mesh_instances.get_mut(0) {
    instance.rotation[1] = now * 0.7;   // угол растёт со временем
}
```

### Добавляем управление камерой (WASD)

```rust
use alkash3d_rs::input::keys;
use alkash3d_rs::math::Vec3;

// внутри цикла, после process_messages():
if engine.input.just_pressed(keys::ESCAPE) { engine.request_exit(); }

let rot_amount = 2.0 * dt;
if engine.input.is_down(keys::ARROW_LEFT)  { engine.camera.rotate_yaw(rot_amount); }
if engine.input.is_down(keys::ARROW_RIGHT) { engine.camera.rotate_yaw(-rot_amount); }
if engine.input.is_down(keys::ARROW_UP)    { engine.camera.rotate_pitch(-rot_amount); }
if engine.input.is_down(keys::ARROW_DOWN)  { engine.camera.rotate_pitch(rot_amount); }

let move_speed = if engine.input.is_down(keys::SHIFT) { 10.0 } else { 5.0 };
let forward = (engine.camera.target - engine.camera.position).normalize();
let right = forward.cross(engine.camera.up).normalize();
let move_amount = move_speed * dt;

let mut delta = Vec3::ZERO;
if engine.input.is_down(keys::W) { delta += forward * move_amount; }
if engine.input.is_down(keys::S) { delta -= forward * move_amount; }
if engine.input.is_down(keys::A) { delta -= right * move_amount; }
if engine.input.is_down(keys::D) { delta += right * move_amount; }

engine.camera.position += delta;
engine.camera.target += delta;
```

- `just_pressed` — клавишу нажали **именно в этом кадре** (разовые действия).
- `is_down` — клавиша **зажата сейчас** (непрерывное движение).

## 4. Жизненный цикл движка (`AlkashEngine`)

`AlkashEngine` — главный тип движка. Один экземпляр на всю игру.

### Полный цикл жизни

```
AlkashEngine::new(w, h)   →  заполнить поля значениями по умолчанию
        ↓
set_graphics_settings(...)  (необязательно, ДО init())
set_clear_color(...)        (необязательно)
        ↓
init()                    →  создать окно + GPU + все пайплайны
        ↓
[настройка сцены: меши, физика, свет, звук, мир]
        ↓
┌─────────────────────────────────────────────┐
│  while is_running() {                        │
│      process_messages()      // события      │
│      ... игровая логика ...                  │
│      update(dt, gravity, cam, view_proj)     │
│      render_frame()          // нарисовать   │
│  }                                            │
└─────────────────────────────────────────────┘
        ↓
shutdown()  (или автоматически через Drop)
```

### Конструктор

```rust
let mut engine = AlkashEngine::new(1280, 720);
```

`AlkashEngine::new(width: u32, height: u32) -> Self` — создаёт структуру со
значениями по умолчанию. **Ничего тяжёлого не делает** (создаёт `EngineScheduler`
и канал результатов загрузки чанков).

### Настройки до `init()`

```rust
engine.set_clear_color(0.05, 0.05, 0.1, 1.0);

engine.set_graphics_settings(alkash3d_rs::engine::GraphicsSettings {
    msaa: true, ssao: true, bloom: true, volumetric: true, shadows: true,
    render_scale: 1.0,
});
```

`set_graphics_settings` нужно вызывать **до `init()`** — флаги читаются один раз
при построении рендер-пайплайна.

### Инициализация

```rust
engine.init()?;   // -> Result<()>
```

Порядок: окно → D3D12-устройство → command queue → swap chain → command allocators →
fence → renderer → компиляция шейдеров → root signature → pipeline state →
constant buffer → tonemap/bloom/shadow/occluder/volumetric/SSAO → показать окно.

Для OpenXR (VR): `engine.init_for_xr(adapter_luid, min_feature_level)?`.

### Игровой цикл

```rust
engine.process_messages();   // первый вызов каждый кадр
engine.update(dt, -9.8, camera_pos, view_proj.to_cols_array());
engine.render_frame()?;
```

`update()` тикает подсистемы в порядке:
1. Физика — `physics.update(dt, gravity)`.
2. Синхронизация физики — позиции тел → `Transform` их сущностей.
3. Нативные/Lua скрипты.
4. Python-скрипты (+ hot-reload).
5. День/ночь — солнце + управляемые фонари.
6. Стриминг мира по позиции камеры.
7. Приём завершённых загрузок чанков.
8. Каллинг света — `lights.cull(...)`.
9. Звук — обновляет listener и 3D-позиции.

Параметры `update`: `dt: f32`, `gravity: f32` (обычно `-9.8`),
`camera_pos: [f32;3]`, `view_proj: [f32;16]` (по колонкам).

### Управление циклом

```rust
engine.is_running();          // true, пока работаем
engine.request_exit();        // попросить остановиться
```

### Окно

```rust
engine.set_window_title("Моя игра");
engine.toggle_fullscreen();   // F11-стиль переключение
```

### Завершение

```rust
engine.shutdown();
```

- Ставит `running = false`, сигналит fence и ждёт GPU **до 5 секунд**.
- Если GPU завис — логирует причину и `std::process::exit(1)` (не вешает систему).
- Иначе: чистит меши, освобождает GPU-ресурсы, закрывает окно.
- `Drop` вызовет `shutdown()` автоматически.

### Прогрев пайплайнов

```rust
engine.warm_up_pipelines()?;   // -> Result<bool>
```

Прогоняет один «прогревочный» кадр, чтобы JIT-компиляция PSO прошла до цикла
(иначе первый кадр может упереться в таймаут TDR).

### Диагностика

```rust
if let Some(stats) = engine.physics_stats() { /* тела, контакты, ms */ }
let b = engine.take_update_breakdown();       // разбивка update() по фазам
if let Some(lum) = engine.scene_luminance() { /* средняя яркость кадра */ }
engine.reset_taa();                            // сбросить историю TAA
```

### Полезные константы и функции

```rust
alkash3d_rs::VERSION                              // версия движка
alkash3d_rs::get_device() / get_command_queue() / get_swap_chain() / get_fence()
alkash3d_rs::device_removed_reason() -> Option<String>
```

## 5. Меши, материалы и сцена

### Базовые понятия

- **`Vertex`** — одна вершина: позиция, нормаль, цвет, UV, tangent.
- **`Mesh`** — готовый GPU-меш (вершинный + индексный буфер, материал, bounding sphere).
- **`MeshInstance`** — «экземпляр» меша в мире.
- **`Scene`** — ECS-сцена: сущности (`EntityId`) с компонентами.

### Быстрое создание геометрии (методы `AlkashEngine`)

Все возвращают **индекс меша** (`usize`):

```rust
let tri   = engine.add_triangle();                       // треугольник
let quad  = engine.add_quad(0.0, 0.0, 8.0, 8.0, [0.3, 0.3, 0.4, 1.0]); // плоскость
let cube  = engine.add_cube(1.0);                        // куб (грани разных цветов)
let cube2 = engine.add_cube_colored(1.0, 0.5, 0.5, 0.5, 1.0); // куб одного цвета
let tile  = engine.add_tile(1.0, 0.5, 0.5, 0.5, 1.0);    // «верхняя грань» (для LOD)
let mesh  = engine.add_mesh(my_mesh);                    // свой готовый Mesh
```

- `add_cube(size)` — каждая грань своего отладочного цвета. Для реального
  освещения используй `add_cube_colored`.
- `add_quad(x, y, w, h, color)` — плоскость в плоскости XY. Для пола поверни на −π/2 по X.

### Чем хорош ECS

- **Стабильные `EntityId`** — `(index, generation)`. Обращение по устаревшему
  `EntityId` вернёт `None`, а не данные чужой сущности.
- **Иерархия** — мировые матрицы считаются обходом от корней.
- **Аддитивность** — `render_frame()` рисует и `mesh_instances`, и сущности `scene`.

`EntityId::INVALID` — «заведомо невалидный» ID. Методы: `.index()`, `.generation()`.

`apply_*` нужно звать **каждый кадр**, пока сила действует.

### Чтение состояния

```rust
if let Some(body) = engine.get_physics_body(id) { println!("{:?}", body.position); }
let contacts: &[PhysicsContact] = engine.get_contacts();
if let Some(stats) = engine.physics_stats() { /* ... */ }
```

### Соединения (joints)

```rust
use alkash3d_rs::plugin::joint_type;

let j = engine.add_ball_joint(a, b, [0.0;3], [0.0;3], 100.0);            // шар
let h = engine.add_hinge_joint(a, b, [0.0;3], [0.0;3], [0.0,1.0,0.0], 100.0, 100.0); // петля
let f = engine.add_fixed_joint(a, b, [0.0;3], [0.0;3], 500.0, 500.0);   // сварка
engine.add_constraint(&ConstraintDesc { body_a: a, body_b: b,
    joint_type: joint_type::SLIDER, ..Default::default() });

engine.remove_constraint(j);
if let Some(info) = engine.get_constraint(j) { if info.is_broken != 0 { /* сломался */ } }
for id in engine.get_broken_constraints() { /* сыграть звук/заспавнить обломок */ }
```

Типы (`joint_type`): `BALL = 0`, `HINGE = 1`, `FIXED = 2`, `SLIDER = 3`.

### Raycast

```rust
if let Some(hit) = engine.physics_raycast(origin, [0.0, -1.0, 0.0], 5.0, Some(car_body)) {
    println!("попал в {:?} на {}", hit.point, hit.distance);
}
```

`physics_raycast(origin, direction, max_dist, exclude_body) -> Option<RaycastHit>`.

### Синхронизация со сценой

`spawn_physics_sphere`/`spawn_physics_car` регистрируют связь тело↔сущность, и
`update()` сам синхронизирует позиции в `Transform`. Вручную ничего не нужно.

### Сборки `.alasm`

```rust
let handle = engine.spawn_assembly("car.alasm", [0.0, 1.0, 0.0]);  // -> Option<AssemblyHandle>
```

## 10. Скриптинг и плагины

Три языка скриптов через единый C-ABI:

| № | Язык | Как работает | Метод движка |
|---|------|--------------|--------------|
| 0 | **Python** | hot-reload, встроен (RustPython) | `load_python_script` |
| 1 | **Lua** | DLL-рантайм `alkash3d_luascript.dll` (Lua 5.4) | `load_lua_script` |
| 2 | **Native** (Rust/C++) | DLL, реализующая Scripting API | `load_native_script` |

### Нативный скрипт (Rust/C++ DLL)

```rust
use alkash3d_rs::engine::ScriptHandle;
use alkash3d_rs::plugin::{ScriptEvent, ScriptEventType};

let handle: ScriptHandle = engine.load_native_script(
    "../alkash3d-examplescript/target/release/alkash3d_examplescript.dll", entity)?;

engine.dispatch_script_event(&handle, &ScriptEvent {
    event_type: ScriptEventType::Custom as u32,
    source_entity: 0, target_entity: 0, data: [1.0, 0.0, 0.0, 0.0],
});

engine.unload_native_script(&handle);
```

Скрипт вызывается **каждый кадр** из `update()` через `update_script` с
`ScriptContext`.

### Типы событий (`ScriptEventType`)

```rust
Custom = 0, CollisionEnter = 1, CollisionExit = 2,
ZoneEnter = 3, ZoneExit = 4, Spawned = 5, Despawned = 6
```

`Spawned`/`Despawned` отправляются автоматически.

### Упаковка EntityId в u64

```rust
use alkash3d_rs::engine::pack_entity_id;
let packed: u64 = pack_entity_id(entity);   // (index << 32) | generation
```

### Lua-скрипт

```rust
let handle = engine.load_lua_script(
    "../alkash3d-luascript/target/release/alkash3d_luascript.dll",   // DLL-рантайм
    "scripts/my_script.lua", entity)?;
```

Контракт Lua-скрипта:

```lua
function update(dt, x, y, z, rx, ry, rz)
    y = y + math.sin(os.clock()) * 0.01
    return x, y, z, 1          -- (x, y, z, changed)
end

function on_event(event_type, d0, d1, d2, d3)
    -- 0=Custom, 1=CollisionEnter, ...
end
```

### Python-скрипт (hot-reload)

```rust
engine.load_python_script("scripts/bobber.py", entity)?;
engine.dispatch_python_event(entity, 0, [1.0, 0.0, 0.0, 0.0]);
engine.unload_python_script(entity);
```

Файл следится по mtime — правки подхватываются на следующем кадре (hot-reload).
Синтаксическая ошибка не роняет игру.

### Написать свой нативный плагин (Rust)

1. Объявить `#[repr(C)]` структуры ABI (`PluginAPI`, `ScriptingAPI`, `ScriptConfig`,
   `ScriptEvent`, `ScriptContext`) — побайтово совпадают с
   `alkash3d-rust/src/plugin/{abi,scripting_api}.rs`.
2. Реализовать `create_script`/`destroy_script`/`update_script`/`dispatch_event`/
   `get_active_scripts_count` (и `create_script_with_source`).
3. Экспортировать:

```rust
#[no_mangle]
pub extern "C" fn get_plugin_api() -> PluginAPI { /* ... */ }
```

4. Собрать `cargo build --release`.

### Структуры скриптинга

```rust
pub struct ScriptContext {
    pub entity_id: u64, pub delta_time: f32, pub frame_number: u64,
    pub position: [f32;3], pub rotation: [f32;3],      // вход
    pub out_position: [f32;3], pub out_rotation: [f32;3],
    pub position_changed: u32,                          // 1 = применить out_*
}
pub struct ScriptHandle { pub dll_path: String, pub script_id: u32, pub entity: EntityId }
pub struct ScriptEvent { pub event_type: u32, pub source_entity: u64, pub target_entity: u64, pub data: [f32;4] }
```

## 11. Файловые форматы движка

Каждый формат живёт в `alkash3d-rust/src/<имя>_format.rs`. Главные типы
реэкспортированы: `alkash3d_rs::AltexFile`, `alkash3d_rs::AlworldFile` и т.д.

### Сводная таблица

| Расширение | Магия | Главный тип | Загрузка | Сохранение |
|-----------|-------|-------------|----------|-----------|
| `.altex` | `ALKALTEX` | `AltexFile` | `load(path)` | `save(&self, path)` |
| (внутри `.altex`) | `ALTSCENE` | `AltexScene` | `from_bytes` | `to_bytes` |
| `.alfar` | `ALKALFAR` | `AlfarFile` | `load` | `save` |
| `.alcar` | `ALKALCAR` | `AlcarFile` | `load` | `save` |
| `.alasm` | `ALKALASM` | `AlasmFile` | `load` | `save` |
| `.alroute` | `ALKROUTE` | `AlrouteFile` | `load` | `save` |
| `.alworld` | `ALKWORLD` | `AlworldFile` | `load` | `save` |
| `.alwchunk` | `ALKCHNK\0` | `ChunkContent` | `load_from_file` | `save_to_file` |
| `.almat` | `ALKALMAT` | `AlmatFile` | `load` | `save` |
| `.alps` | `ALKALPS ` | `AlpsFile` | *(нет)* | *(нет)* |
| `.alsnd` | `ALKALSND` | `AlsndFile` | `load` | `save` |
| `.alscript` | `ALKSCRPT` | `AlscriptFile` | `load` | `save` |
| `.aluv` | `ALKALUV ` | `AluvFile` | *(нет)* | `save` (неполное) |
| `.gltf`/`.glb` | — | `gltf::Model` | `gltf::load(path)` | — |

### `.altex` — геометрия и сцена

```rust
use alkash3d_rs::altex_format::AltexFile;
let mut f = AltexFile::new();
let tex = f.add_texture(256, 256, 0, &pixels, "ground");
let mat = f.add_material([1.0; 4], tex, "ground_mat");
let mesh = f.add_mesh(verts, indices, "floor");
f.add_object(mesh, transform, "floor_obj");
f.save("scene.altex")?;
let loaded = AltexFile::load("scene.altex")?;
```

### `.alfar` — освещение

```rust
use alkash3d_rs::alfar_format::AlfarFile;
let mut f = AlfarFile::new();
f.add_light(light, "lamp");
f.save("lights.alfar")?;
let loaded = AlfarFile::load("lights.alfar")?;
// loaded.ambient, loaded.global_settings, loaded.lights
```

> ⚠️ `save()`/`load()` пока сохраняют только ambient + global settings + отдельные
> источники; группы/анимации не пишутся.

### `.alcar` — игровые характеристики машины

```rust
use alkash3d_rs::alcar_format::AlcarFile;
let mut f = AlcarFile::new();
f.set_mesh("car.altex");
f.save("car.alcar")?;
```

Готовые пресеты: `create_police_car()`, `create_sports_car()`.

### `.alasm` — разборка на детали

```rust
use alkash3d_rs::alasm_format::{AlasmFile, AssemblyCategory, PartRecord, NONE_ID};
let mut f = AlasmFile::new("car", AssemblyCategory::Vehicle);
let root = f.add_root_part(PartRecord { /* ... */ });
let child = f.add_child_part(root, PartRecord { /* ... */ });
f.save("car.alasm")?;
```

`NONE_ID = u32::MAX` — «нет ссылки». Типы шарниров — `joint_type`: `BALL/HINGE/FIXED/SLIDER`.

### `.alroute` — маршруты

```rust
use alkash3d_rs::alroute_format::{AlrouteFile, Waypoint};
let mut f = AlrouteFile::new();
f.add_route("patrol", &[Waypoint { position: [0.0;3], wait_time: 0.0, speed_limit: 10.0, action_id: 0 }], 0);
f.save("routes.alroute")?;
```

### `.alworld` + `.alwchunk` — открытый мир

```rust
use alkash3d_rs::alworld_format::{AlworldFile, ChunkContent};

let path = AlworldFile::create_and_save_demo_world("demo_world")?;
let world = AlworldFile::load(&path)?;

let mut chunk = ChunkContent::new();
chunk.add_object("house.altex", transform);
chunk.add_object_with_physics("crate.altex", transform, 5.0);
chunk.save_to_file("chunk_0_0_0.alwchunk")?;
```

Флаг точки спавна: `GLOBAL_OBJECT_FLAG_SPAWN_POINT = 0x8000_0000`.

### `.almat` — библиотека материалов

```rust
use alkash3d_rs::almat_format::{AlmatFile, MaterialDefinition, NO_TEXTURE};
let mut f = AlmatFile::new();
f.add_material_definition(MaterialDefinition { /* ... */ }, "brick");
f.save("materials.almat")?;
```

### `.alsnd` — пространственный звук

```rust
use alkash3d_rs::alsnd_format::AlsndFile;
let mut f = AlsndFile::new(2, 48000);
f.save("sounds.alsnd")?;
```

### `.alscript` — скрипты

```rust
use alkash3d_rs::alscript_format::AlscriptFile;
let mut f = AlscriptFile::new();
f.register_python_script("bobber", "def update(...): ...");
f.register_lua_script("ai", "lua.dll", "ai.lua", 0);
f.register_native_script("ai", "ai.dll", 0);
f.save("scripts.alscript")?;
```

`script_type`: `0 = Python`, `1 = Lua`, `2 = Native`, `3 = зарезервировано`, `4 = Hybrid`.

### `.aluv` — кинематографика

```rust
use alkash3d_rs::aluv_format::AluvFile;
let mut f = AluvFile::new();
f.save("intro.aluv")?;   // ⚠️ save() неполный, load() нет
```

### glTF 2.0

```rust
use alkash3d_rs::gltf;
let model = gltf::load(std::path::Path::new("car.glb"))?;   // -> Result<Model, String>
```

Не поддерживает Draco/meshopt, sparse, `KHR_texture_transform`; анимации/скелеты
пропускаются. Загрузка в движок: `engine.load_gltf("car.glb")?`.

### Общий паттерн

```rust
let mut f = XxxFile::new();          // создать
f.add_*(...);                        // наполнить
f.save("path.xxx")?;                 // сохранить

```

## 12. Открытый мир и стриминг чанков

Движок стримит мир из `.alworld` (метаданные) + `.alwchunk` (содержимое чанков).
Чанки грузятся/выгружаются **в фоне** через планировщик.

### Загрузка мира

```rust
engine.load_world("maps/city/world.alworld", None)?;   // -> io::Result<()>
engine.load_demo_world("demo_world")?;                 // демо-мир за один вызов

if let Some((pos, yaw)) = engine.world_spawn_point() {
    engine.camera.position = pos;   // yaw — угол поворота по Y (радианы)
}

engine.unload_world();                                  // переход на другой уровень
```

- `load_world(alworld_path, chunks_dir: Option<&str>)` — включает стриминг.
  `chunks_dir = None` = подпапка `chunks` рядом с `.alworld`.
- `world_spawn_point() -> Option<(Vec3, f32)>` — позиция + yaw точки спавна.
- `unload_world()` — выгружает все чанки.

### Свет из `.alfar`

```rust
let added = engine.load_lights_from_alfar("lights/night.alfar")?;   // -> io::Result<u32>
```

Требует `init_lights()`. Также сохраняет `engine.light_ambient` и
`engine.light_global_settings`.

### Простой фонарь

```rust
engine.add_street_light(0.0, 3.0, 0.0);   // -> Option<u32>
```

### `.alasm`-сборки

```rust
let handle = engine.spawn_assembly("cars/sedan.alasm", [0.0, 1.0, 0.0]); // -> Option<AssemblyHandle>
```

Требует `init_physics()`. Каждая деталь = одно физическое тело + один `joint` к родителю.

### Загрузка glTF

```rust
let model = engine.load_gltf("models/car.glb")?;   // -> Result<GltfModel, String>
for &m in &model.meshes {
    engine.mesh_instances.push(MeshInstance::new(m).at(0.0, 0.0, 0.0));
}
```

### Как устроен стриминг

- `WorldStreamingState` — состояние мира (файл, папка чанков, состояние чанков, очереди).
- `update_world_streaming(camera_pos)` — решает загрузку/выгрузку по
  `load_distance`/`unload_distance`.
- Фоновая загрузка — через `EngineScheduler`; результат применяется в `drain_pending_chunk_io()`.
- Чанк = набор объектов (ссылка на `.altex`), у объекта может быть физика
  (`CHUNK_OBJECT_FLAG_HAS_PHYSICS`).

## 13. Редактор (`alkash3d-editor`)

Отдельный крейт `alkash3d-editorapp` — редактор на **egui/wgpu**. Линкуется с
`alkash3d_rs` **как rlib**, поэтому файлы редактора побайтово совместимы с движком.

### Запуск

```bash
cd alkash3d-editorapp
cargo run --release
```

### Что умеет

- **Сцена**: иерархия объектов, инспектор, выбор, видимость/блокировка.
- **Инструменты**: Select / Move / Rotate / Scale (Q/W/E/R) + 3D-гизмо с привязкой.
- **Edit Mode** (Tab): выбор вершин/граней (1/2), extrude (E), удаление (Delete).
- **Undo/redo** (Ctrl+Z / Ctrl+Y), история до 100 команд.
- **Импорт моделей**: `.obj` (через tobj); конвертеры `.fbx`/`.gltf`/`.blend` через
  headless Blender (существуют, но в живом пути не подключены).
- **Импорт/экспорт родных форматов** через `alkash3d_rs`: `.altex`, `.alworld`,
  `.alfar`, `.almat`, `.alsnd`, `.alcar`, `.alroute`, `.alscript`, `.alasm`.
- **Спец-редакторы**: звуки, маршруты, скрипты, машины, материалы, сборки, UV.
- **Анимация**, **частицы**, **WorldStreamer**, **импорт города**, **Discord Rich Presence**.

### Ключевые типы

```rust
pub struct EditorApp { /* сцена, история, камера, инструменты, панели, ... */ }
pub struct Scene { /* name, objects: HashMap<Uuid, GameObject>, ... */ }
pub struct GameObject { /* id, name, transform, object_type, parent, ... */ }
pub enum ObjectType { Empty, Mesh(...), Light(...), Camera(...), ParticleSystem(...), AudioSource(...), ScriptedEntity(...), SpawnPoint }
pub enum EditorTool { Select, Move, Rotate, Scale }
pub enum EditorCommand { CreateObject, DeleteObject, ModifyTransform, ModifyMesh }
pub struct CommandHistory { /* undo_stack, redo_stack */ }
```

### Цикл и GPU

- `main()` → `eframe::run_native` (wgpu), окно 1600×900.
- Цикл — `impl eframe::App::update`.
- `GpuRenderer` (wgpu): PBR-пайплайн, общий vertex/index буфер, offscreen-текстура
  в `egui_wgpu` без CPU-readback. Есть CPU-fallback (wireframe).

### Замечания

- `config.rs` (`PerformanceConfig`) — заготовка, не подключена.
- Импорт третьих форматов фактически только OBJ в живом пути.

> Демо с физикой требуют `inertial.dll`; демо со светом — `alkash3d_firstfires.dll`.

### Дополнительные крейты

- **`alkash3d-inertial`** — физический плагин `inertial.dll`. Fortran-солвер,
  gfortran, цель `x86_64-pc-windows-gnu`. Экспортирует `get_plugin_api()` (7 полей)
  и `inertial_softbody_step()`. `PhysicsAPI` — 23 функции.
- **`alkash3d-FirstFires`** — плагин света `alkash3d_firstfires.dll`. CPU-каллинг.
  Экспортирует `get_plugin_api()`, `firstfires_prepare_sun(SunInput) -> SunFrame`,
  `firstfires_point_lamp(PointLamp) -> GPULight`. `LightAPI` — 13 функций.
- **`alkash3d-luascript`** — Lua-плагин `alkash3d_luascript.dll`. Lua 5.4 (vendored).
  Контракт: `update(dt,x,y,z,rx,ry,rz) -> (x,y,z,changed)`, опц. `on_event(...)`.
- **`alkash3d-examplescript`** — референсный нативный скрипт `alkash3d_examplescript.dll`
  («Bobber»: покачивание + реакция на события).
- **`alkash3d-execfile`** — минимальный C-ABI вьювер `alkash3d_execfile.exe`.
  Грузит `alkash3d_rs.dll` через libloading и вызывает ~20 C-ABI символов.
- **`alkash3d-msts`** — загрузчик MSTS (`route_view`). Читает `.s`, `.ace`, `.w`,
  `.t`/`_y.raw`, `.eng`/`.wag`, `.tdb`, `tsection.dat`, `.sms` прямо в движок.

### Как всё связано

```
alkash3d-rust (ядро, alkash3d_rs)
  ├─ грузит inertial.dll            (физика, get_plugin_api → PhysicsAPI)
  ├─ грузит alkash3d_firstfires.dll (свет, get_plugin_api → LightAPI)
  ├─ грузит alkash3d_luascript.dll  (Lua, get_plugin_api → ScriptingAPI)
  ├─ грузит alkash3d_examplescript.dll (Native-скрипт)
  └─ встроенный звук (XAudio2), Python (RustPython)

alkash3d-editorapp (редактор) — линкуется с alkash3d_rs как rlib
alkash3d-execfile (вьювер) — грузит alkash3d_rs.dll через libloading
alkash3d-msts (загрузчик) — зависит от alkash3d_rs + alkash3d-firstfires
```

## 16. Переменные окружения и известные проблемы

### Переменные окружения

| Переменная | Что делает |
|-----------|------------|
| `ALKASH3D_GBV` | Включить GPU-Based Validation (только лёгкие демо) |
| `ALKASH3D_PREPASS=0` | Выключить depth-предпроход |
| `ALKASH3D_HIDDEN=1` | Не показывать окно |
| `ALKASH3D_SHOT` | Сохранить снимок кадра в PNG |
| `ALKASH3D_VRAM=0` | Не переносить меши в видеопамять |
| `ALKASH3D_XR_MODE=ar` | Режим AR для `xr_demo` |
| `ALKASH3D_DIAG_NO_SHADOW=1` | (example_minimal) выключить тени |
| `ALKASH3D_DIAG_NO_VOLUMETRIC=1` | (example_minimal) выключить volumetric |
| `ALKASH3D_DIAG_NO_BLOOM=1` | (example_minimal) выключить bloom |
| `ALKASH3D_DIAG_TEXTURED_FLOOR=1` | (example_minimal) пол с текстурой |
| `ALKASH3D_DIAG_PHYSICS=1` | (example_minimal) включить физику |
| `ALKASH3D_DIAG_CAR=1` | (example_minimal) спавн физической машины |
| `ALKASH3D_DIAG_MANY_OBJECTS=1` | (example_minimal) добавить 20 кубов |
| `ALKASH3D_DIAG_TIME_OF_DAY=1` | (example_minimal) `set_time_of_day(13.0)` |
| `ROUTE_*` | Настройки вьювера `alkash3d-msts` |

### Известные проблемы

1. **GPU-Based Validation выключен по умолчанию** — на тяжёлых сценах GBV может
   раздуть кадр до минут → полный TDR-сброс системы.
2. **Нерешённое зависание GPU на «кадре 2»** (root-descriptor, `E_INVALIDARG`).
   Устранено только следствие: `shutdown()` больше не вешает систему (fence-таймаут
   5 с → `std::process::exit(1)`).
3. **`.alasm` ещё не связан с `.alcar`** через `custom_data`.
4. **Физический ABI** не создаёт новые тела посреди симуляции из `.alasm`
   (кроме начального спавна).
5. **`.alfar`** — группы/анимации не пишутся на диск.
6. **`.aluv`** — `save()` неполный, `load()` нет. **`.alps`** — без сериализации.
7. **Импорт fbx/gltf/blend в редакторе** — фактически работает только OBJ.

### Частые ошибки новичка

- **Забыл `process_messages()`** — окно не отвечает, ввод не работает.
- **`set_graphics_settings` после `init()`** — эффекта нет; вызывай до `init()`.
- **Физика/свет/звук не работают** — не вызвал `init_physics`/`init_lights`/
  `init_audio`, или DLL не по пути.
- **Камера не двигается** — движок не двигает камеру сам; пиши логику через
  `engine.camera` + `engine.input`.
- **Окно зависает при ресайзе** — ресайз откладывается до конца перетаскивания (нормально).

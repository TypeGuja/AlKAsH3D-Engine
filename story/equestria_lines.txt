# Buckshot Equestria — реплики (черновик 2026-10-17, правь свободно)
#
# Формат:
#   [round N имя акт жизни]          — заголовок партии
#   [round N имя+имя акт жизни+жизни] — парная партия: жизни у каждой пони свои
#   ключ текст                        — реплика; в парных партиях: ключ имя: текст
#   red(текст)                        — красный текст
# Ключи:
#   host   — ведущий объявляет соперника (перед партией)
#   intro  — соперник садится за стол
#   hurt   — соперника ранили (первый раз за партию)
#   last   — у соперника осталась последняя жизнь (после смерти пони молчат)
#   win    — соперник выиграл (игрок проиграл), последняя фраза перед чёрным экраном
# Сквозная линия: соперники проговариваются, что всех позвала «она» — Искорка.
